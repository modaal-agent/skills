# Changelog

Every release, newest first: the version, the date, and what a consumer pinning the previous
version has to change.

A release carries one `<name>.zip` per skill, for upload to claude.ai and the Claude desktop app;
[README.md](README.md) §"Install" has the steps. The other install channels read `main`, and take a
change when it lands there. [CONTRIBUTING.md](CONTRIBUTING.md) §"Releasing" says which part of the
version a change bumps.
